# Surebet Signal

Десктоп-приложение (Windows 11): следит за вилками на **surebet.com** и шлёт сигналы по вилкам
с **Pinnacle** в Telegram (событие, коэффициент Pinnacle, ставка, доход %).

Главное окно — сам сайт surebet: ты логинишься и ставишь свой фильтр там, а приложение
читает ровно то, что видишь ты, и сигналит о нужных вилках. Фоновая работа — в трее.

## Как пользоваться
1. Запусти приложение. Откроется окно surebet — **войди и выставь фильтр** (Pinnacle, нужный порог дохода).
2. В **панели** (трей → «Панель и настройки») впиши **токен Telegram-бота** и **chat_id**, нажми «Сохранить» и «Тест в Telegram».
3. Готово — как появится вилка с Pinnacle, прилетит сигнал. Окно можно свернуть в трей, работа продолжится.

Сессия surebet хранится внутри приложения (логин не сбрасывается). Секреты (токен) шифруются
через системный safeStorage и в код/репозиторий не попадают.

## Разработка (Mac/Windows)
```bash
npm install
npm start        # запуск приложения
npm test         # тесты логики (парсер/фильтр/формат/антиспам)
```

## Сборка Windows-установщика
Локально (на Windows):
```bash
npm run dist     # установщик в папке release/, без публикации
```

## Авто-обновление (через GitHub Releases)
1. В `package.json` → `build.publish.owner` укажи свой GitHub-логин (repo: `surebet-signal-app`).
2. Залей проект в репозиторий `surebet-signal-app` на GitHub.
3. Релиз = пуш тега версии:
   ```bash
   npm version patch        # поднимет версию и создаст тег vX.Y.Z
   git push --follow-tags
   ```
   GitHub Actions (`.github/workflows/build.yml`) сам соберёт Windows-установщик и опубликует релиз.
4. Установленное приложение проверяет релизы и **само скачивает/ставит обновление**.

Так чинятся баги: правим код → `npm version patch` → пуш тега → у тебя обновляется автоматически.

## Примечания
- Установщик без подписи → Windows SmartScreen покажет «неизвестный издатель»: «Подробнее → Выполнить».
- Если surebet попросит войти заново — открой приложение и залогинься; придёт и Telegram-предупреждение.
